# 🛍️ Konga Clone — E-Commerce Website

A responsive **Konga-inspired e-commerce web application** built as a full-stack web development project. The application provides a modern shopping experience with product browsing, authentication, cart management, wishlist functionality, checkout, and online payment integration.

## 🚀 Live Demo

**Live Website:** https://kongaprojectapp.web.app/

**GitHub Repository:** https://github.com/davthmm-link/Konga-project

---

## 📌 About The Project

This project is a functional e-commerce website inspired by the Konga shopping platform.

The goal was to build a realistic online shopping experience while practicing frontend development, JavaScript functionality, user authentication, local storage, payment integration, Git/GitHub workflow, and Firebase deployment.

The project has been deployed using **Firebase Hosting** and is accessible online.

## 🔐 Authentication

Firebase Authentication is used to manage user registration and login.

Users can:

* Create an account
* Log in securely
* Stay authenticated while browsing
* Log out of their account

Protected functionality requires the user to be authenticated.

---

## 🛒 Shopping Features

The application allows users to:

1. Browse available products
2. Search for products
3. Filter products by category
4. Sort products by price or name
5. View product details
6. Add products to their cart
7. Increase product quantities
8. Manage their wishlist
9. Proceed to checkout

Cart and wishlist information is managed through browser storage.

---

## 💳 Payment

The project integrates **Paystack** for checkout/payment processing.

The payment flow allows users to proceed from their shopping cart to the checkout process and initiate payment through Paystack.

## 💻 Running The Project Locally

Clone the repository:

```bash
git clone https://github.com/davthmm-link/Konga-project.git
```

Navigate into the project:

```bash
cd Konga-project
```

Open the project in Visual Studio Code:

```bash
code .
```

Because this is a frontend web project, you can run it locally using a development server such as **Live Server** in VS Code.
